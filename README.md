# Linear Search in Java

## Description
This Java program searches for a given element in an array using the linear search algorithm.

Linear search checks each element sequentially until the target element is found or the array ends.

## Concepts Used
- Java Arrays
- For Loop
- Conditional Statements
- Linear Search Algorithm
- Scanner Class

## Sample Input
```text
Enter element to search: 30
```

## Sample Output
```text
Element found at index: 2
```

## Time Complexity
- Best Case: O(1)
- Average Case: O(n)
- Worst Case: O(n)

## How to Run
Compile:
```bash
javac LinearSearch.java
```

Run:
```bash
java LinearSearch
```

## Purpose
Created for Java programming practice, college lab preparation, and understanding searching algorithms.
